# Домашняя работа №2

Проект создан для работы с датасетом `dirty_financial_transactions.csv`.

## Структура

- `data_loader.py` — загрузка CSV, JSON и данных по URL.
- `data_processing.py` — удаление дубликатов, преобразование типов и очистка категорий.
- `missing_values.py` — подсчет, отчет и заполнение пропусков.
- `visualization.py` — гистограмма, линейный график, диаграмма рассеяния и закрытие графиков.
- `model.py` — простая линейная регрессия.
- `main.py` — последовательный запуск всех модулей.

## Как запустить

1. Поместить все файлы в одну папку.
2. Установить библиотеки:

```bash
pip install -r requirements.txt
```

3. Запустить:

```bash
python main.py
```

## Что показывает модель

Модель линейной регрессии пытается предсказать `Price` по `Quantity`.
